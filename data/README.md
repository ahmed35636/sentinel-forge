# Fixture data

All events are synthetic. No command in this directory is executed by the projects.
The strings describe an investigation scenario: cmd → PowerShell → a lab reader
and scheduled-task creation, with a separate PsExec process and benign control.
IP addresses come from RFC 5737 documentation ranges. The threat-intelligence
match is a fixture, not a real-world claim about the address.

Record IDs are unique within each host. Process GUIDs are abbreviated fixture
identifiers; real exports retain the GUIDs generated by Sysmon.
